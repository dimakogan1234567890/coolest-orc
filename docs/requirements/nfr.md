## NFR-001. Производительность

- **Требование, метрика и порог:** p95 обработки чтения состояния ≤ 300 мс, игровой команды ≤ 500 мс; доля неожиданных 5xx < 1%.
- **Основание и связи:** BR-001, BR-002; US-001, US-002, US-004, US-005.
- **Условия измерения:** 20 одновременно активных партий по 4 участника, 20 запросов/с, 10 минут после 2 минут прогрева; сервер и БД на стенде 2 vCPU / 4 ГБ, без Unity-рендера и задержки внешней сети. Валидные команды сериализованы по партии.
- **Реализация / схема / ADR:** API и игровой сервис; D-02 (PLAN). Схемы и ADR пока запланированы на КТ-2, ссылок на несуществующие файлы нет.
- **Метод проверки:** Сбор histogram по типам операций и нагрузочный прогон PERF-01 с фиксированным seed; отдельно считать предметные 4xx.
- **Отчёт и факт:** отсутствуют; PLAN, не измерено.
