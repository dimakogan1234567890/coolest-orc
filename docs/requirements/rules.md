# Правила партии, версия 1.0

Владелец: Коган Дмитрий Андреевич. Версия: 1.0 / кандидат cp1. Дата: 12.11.2026.

Статус: DRAFT - подготовлено, согласование КТ-1 не выполнено.

Приоритет: последние решения автора → этот реестр → исходный PDF как справочный материал. Старые варианты нейтральной ничьей, запрета повторного оружия, отсутствия лимита руки и добровольного пропуска неприменимы.

| ID | Правило |
| --- | --- |
| RULE-001 | 2-4 игрока, пять территорий. У каждого игрока на каждой территории четыре места для орков: всего 20. |
| RULE-002 | Признаки от младшего к старшему: Точилы, Швырялы, Рубилы, Крушилы, АААААА. Точилы изображаются кулаком с когтями, Рубилы - клинком. |
| RULE-003 | 124 уникальные карты: 40 с одним признаком, 40 с двумя, 20 обычных с тремя, 10 с четырьмя, 2 с пятью, 2 близнецов и 10 супероружий (по два каждого признака). Итого 114 орков и 10 оружий. |
| RULE-004 | Все руки открыты для участников своей партии. Порядок будущих карт колоды, токены и внутренние секреты не являются открытой игровой информацией. |
| RULE-005 | Начальная рука - 5 карт. Первый игрок определяется случайно. В начале его обычного хода сервис один раз добирает до 6, затем игрок разыгрывает одну карту и остаётся с 5. |
| RULE-006 | Если допустимое действие существует, игрок обязан ходить. Добровольного пропуска нет. Неверная команда не расходует ход, не меняет состояние и не запускает повторный добор. |
| RULE-007 | Обычный орк занимает своё свободное место на открытой территории. Пятый орк и размещение на закрытой территории запрещены. Карты в ряду сохраняют порядок выкладки. |
| RULE-008 | Близнецы: сторона 1 = Рубилы, Крушилы, АААААА; сторона 2 = Точилы, Швырялы, Рубилы. Сторона выбирается при размещении и затем неизменна. Просмотр/переворот в руке не является ходом. |
| RULE-009 | Супероружие выключает один свой признак у всех карт всех игроков на выбранной открытой территории, включая будущие карты. Оружие идёт в сброс и занимает один ход, но не место орка. |
| RULE-010 | Повторное применение того же вида оружия разрешено и расходует другую карту. Оно допустимо также после размещения всех 20 собственных орков, пока есть открытая территория. Повтор доставки одной и той же команды не расходует карту повторно. |
| RULE-011 | Сравнивается полный профиль. По очереди рассматриваются каре, тройки, пары и одиночные признаки. На каждом уровне сначала большее число комбинаций, затем более сильные признаки в порядке убывания. Если уровень полностью равен, переход к следующему. Выключенные признаки имеют эффективное количество 0. |
| RULE-012 | Территория закрывается, когда каждый участник разместил на ней четыре орка. Очко получают только игроки с максимальным полным профилем; каждый равный максимум получает 1. Слабейшие не получают очков. Результат фиксируется один раз; дальнейшие действия на территории запрещены. |
| RULE-013 | Если после добора допустимых действий нет и они уже не могут появиться, участник ждёт итог с шестью картами. Ему больше не дают ход и не добирают карты. Он сохраняет право на очки и просмотр. |
| RULE-014 | Партия завершается после закрытия всех пяти территорий. Побеждают все игроки с максимальным количеством очков. Никакого сравнения лучших выигранных комбинаций при равенстве очков нет. Уточнение автора 12.11.2026 имеет приоритет перед исходным PDF. |
| RULE-015 | В MVP обрыв связи не исключает игрока и не передаёт его карты. В его ход партия ждёт; возврат по токену продолжает сохранённую фазу без дополнительного добора. Замена ботом и исключение перенесены в следующий релиз. |
| RULE-016 | При будущей реализации исключения: карты на поле остаются, игрок исключён до конца партии и больше не получает очки. Это правило следующего релиза, а не реализованное поведение MVP. |
| RULE-017 | Для текущего набора без дополнительных способов добора колода не исчерпывается: на поле не более 80 карт, в руках не более 24, в сбросе не более 10; в колоде остаётся не менее 124-80-24-10=10. Пустая колода при этих условиях - нарушение инварианта, а не штатный сценарий. |
| RULE-018 | В UI выбор своей карты скрывает руки и расширяет территории; обычный тап по разрешённой территории или отпускание карты выполняет ход без подтверждения. Уточнения остаются для стороны близнецов и повторного оружия. Сервер проверяет правила независимо от UI. |
