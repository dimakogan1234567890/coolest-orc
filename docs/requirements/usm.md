# User Story Map

Владелец: Коган Дмитрий Андреевич. Версия: 1.0 / кандидат cp1. Дата: 12.11.2026.

Статус: DRAFT - подготовлено, согласование КТ-1 не выполнено.

По горизонтали - пользовательский путь; по вертикали - дорожки акторов и релизные срезы. **Две дорожки MVP входят в линию MVP полностью.** Участник включает организатора после старта. Технические задачи CI/БД находятся в backlog, а не выдаются за пользовательские истории.

| Срез / актор | Собрать компанию | Присоединиться | Начать и понять поле | Сыграть партию | Получить результат |
| --- | --- | --- | --- | --- | --- |
| MVP / Организатор | US-001 Создать комнату | Передать код друзьям | US-003 Начать партию | Участвует как игрок | Читает общий итог |
| MVP / Участник | Получить код | US-002 Войти | US-004 Увидеть стол | US-005/006/007 Сыграть карту; US-008 Очередь; US-011 Вернуться | US-009 Очки; US-010 Итог |
| Следующий релиз | US-101 Hot seat | US-102 Боты | US-104 Язык и звук | US-103 Исключить / заменить | Статистика партий |
| Вне scope | Публичный подбор | Аккаунты и соцсеть | Магазин и платежи | Новые правила / сезоны | Рейтинг и турниры |

## Передача результата между акторами

Организатор получает код (US-001) → передаёт приглашённому вне приложения → приглашённый входит (US-002) → организатор видит состав и запускает (US-003) → все участники получают начальный снимок (US-004). Далее одинаковая роль участника: выбор действия → проверка → результат хода → ход следующего.
