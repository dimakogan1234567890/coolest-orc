Проект выполняю один: **Коган Дмитрий Андреевич**. Ответственность: правила, клиент, сервер, тесты и документы. Тексты и исходники прототипа подготовлены с помощью AI; проверка и объяснение решений остаются задачей автора.

## Что здесь можно проверить

Прочитать OpenAPI и примеры, открыть SVG, сопоставить каждый US/NFR со схемой и будущим тестом. SVG нарисованы, а их редактируемый источник — `docs/architecture/diagrams.py`; перегенерация: Python + ReportLab, `python docs/architecture/diagrams.py`. Используются Arial из Windows; на другой системе укажите пути к шрифту с кириллицей.

Отчёт [local-baseline.txt](docs/quality/local-baseline.txt) содержит результаты существующего локального ядра 0.2.0: 22 проверки, 1080 партий. [baseline.json](docs/quality/baseline.json) фиксирует хеши проверяемых исходников. Это перенос локального отчёта от 23.11.2026, не новый прогон сервера или CI. Исходники игры находятся в соседнем рабочем проекте `Orcs.Unity`, в документальный комплект они не включены.

## Чего не хватает до полной КТ-2

1. Реализовать серверный путь «создать комнату → войти → начать → сыграть карту → записать → прочитать» с проверкой ошибочного запроса.
2. Добавить миграции, Dockerfile, compose.yaml, .env.example с фиктивными значениями и зафиксированные зависимости.
3. Запустить CI: формат, компиляция, тесты, сборка, поиск секретов; проверить, что сломанный тест/формат делает pipeline красным.
4. Пройти чистый checkout, измерить исходное покрытие и дать ссылки на реальные логи одного SHA.
5. После этого сделать коммит, неподвижный тег cp2 и обновить таблицу контрольных точек ссылками на SHA, демо и CI. Не выдавать этот черновик документов за выполненный каркас.

Документы можно положить в текущий репозиторий отдельной веткой, сохранив историю КТ-1. В этом каталоге нет копии `.git`, и ничего в GitHub не опубликовано. Материал для защиты пока не включён.
