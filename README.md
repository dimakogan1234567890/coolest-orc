# Самый крутой орк

Карточная игра про орков для 2–4 человек. Игроки занимают пять территорий, собирают комбинации и мешают соперникам супероружием. Клиент — Unity для Android, сетевая партия и её состояние — на сервере.

Проект делаю один: **Коган Дмитрий Андреевич**. Отвечаю за правила, клиент, сервер, тесты и документацию. Задачи и оценки — в [плане](docs/plan/backlog.md).
